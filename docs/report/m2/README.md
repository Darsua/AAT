# Milestone 2 LaTeX report

This directory contains the modular M2 report scaffold for the BNPB Disaster Coordination Platform. The manuscript is in Indonesian; this guide and the repository's other Markdown documentation use English. Files are split by chapter and problem to reduce editing conflicts.

## Structure

```text
docs/report/m2/
├── main.tex                       # Entry point
├── preamble.tex                   # Page layout, packages, tables, and code listings
├── references.bib                 # BibTeX references
├── chapters/
│   ├── 00_cover.tex               # Cover and team details
│   ├── 00_frontmatter.tex         # Contents, lists of tables/figures, and contribution table
│   ├── 01_pendahuluan.tex         # Introduction, objectives, assumptions, and M1 changes
│   ├── 02_arsitektur.tex          # Architecture, services, communication, storage, technology, deployment & topology
│   ├── 03_solusi_p1.tex           # Problem 1 solution and discussion
│   ├── 03_solusi_p2.tex           # Problem 2 solution and discussion
│   ├── 03_solusi_p3.tex           # Problem 3 solution and discussion
│   ├── 03_solusi_p4.tex           # Problem 4 solution and discussion
│   ├── 03_solusi_p5.tex           # Problem 5 solution and discussion
│   └── 04_petunjuk.tex            # Environment setup, execution steps, and verification
├── appendix/
│   └── ai_declaration.tex         # AI-use declaration and Form Penggunaan AI
└── figures/                       # Report-specific visual assets
```
